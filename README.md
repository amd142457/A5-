1... var, let, এবং const এর মধ্যে পার্থক্য কী?

var, let এবং const হলো JavaScript এ variable declare করার keyword।

var: এটি পুরনো পদ্ধতি। এটি function scoped এবং একই variable আবার declare করা যায়।

let: এটি block scoped। একই variable আবার declare করা যায় না কিন্তু value পরিবর্তন করা যায়।

const: এটিও block scoped। একবার value দিলে পরে তা পরিবর্তন করা যায় না।

2..Spread operator (...) কী?

Spread operator (...) ব্যবহার করা হয় array বা object এর element গুলোকে আলাদা করে ছড়িয়ে (spread) দেওয়ার জন্য।

এটি সাধারণত array copy করা, merge করা বা নতুন array তৈরি করার জন্য ব্যবহার করা হয়।

3... map(), filter(), এবং forEach() এর মধ্যে পার্থক্য কী?

এই তিনটি method array এর উপর কাজ করে।

map(): array এর প্রতিটি element এর উপর কাজ করে এবং একটি নতুন array return করে।

filter(): condition অনুযায়ী element বেছে নিয়ে একটি নতুন array return করে।

forEach(): array এর প্রতিটি element এর উপর কাজ করে কিন্তু কোনো নতুন array return করে না।
4... Arrow Function কী?

Arrow Function হলো JavaScript এ function লেখার একটি ছোট ও সহজ পদ্ধতি।

এতে function keyword ব্যবহার করতে হয় না এবং => চিহ্ন ব্যবহার করা হয়।

৫️... Template Literals কী?

Template Literals হলো JavaScript এ string লেখার একটি আধুনিক পদ্ধতি যেখানে backtick ( ) ব্যবহার করা হয়।

এতে variable সহজে string এর মধ্যে বসানো যায় ${} ব্যবহার করে।
